Documented Rules & Code Architecture

The calculation algorithm adheres to the official Institute of Engineering (IOE), Tribhuvan University semester evaluation standard:

  • P_board = (Board Obtained / Board Full) * 100
  • P_internal = (Internal Obtained / Internal Full) * 100
  • Delta_P = P_internal - P_board
  • If Delta_P <= 20, Penalty = 0% and Adjusted Internal = Original Internal.
  • If Delta_P > 20, Penalty = (Delta_P - 20) / 200.
  • Adjusted Internal = Original Internal * (1 - Penalty).

Note: Theory pass marks require a minimum of 40% in board exam obtained score prior to adding internal marks.
